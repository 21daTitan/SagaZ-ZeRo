## Decisão de custo

Nenhuma instalação automática de navegador social, sessão, voz, proxy, modelo pesado ou API paga. Primeiro diagnosticar o ambiente e testar pequeno; depois propor apenas o que remove um gargalo medido. Não se presume que software aberto torne todos os modelos, planos ou serviços associados gratuitos.
