# SagaZ ZERO — referência ZION

A referência visual é a imagem enviada pelo usuário: painel de terminal azul escuro, tipografia monoespaçada, chuva vertical de caracteres, scanlines discretas, eventos de inicialização e comando na base.

## Aplicação

- Identidade SAGAZ ZERO, acentos azul/ciano e painel escuro.
- Canvas de caracteres e sobreposição de scanlines sem bloquear cliques.
- Movimento reduzido respeitado; canvas desabilitado nesse modo.
- Log inicial usa versão, número de referências, modo de modelo e catálogo real das skills. Não inventa hardware, RAM, ferramentas ou modelo carregado.
- Barra de comandos limitada às funções locais da interface. Não executa shell nem eval.
- Console, Pesquisa, Skills, Projetos e Conexão permanecem separados.
- Layout adapta navegação e formulários ao celular; foco e labels preservados.

## Comandos

| Comando | Efeito |
|---|---|
| /help ou /modules | Ajuda dos comandos |
| /skills | Catálogo das seis skills |
| /research | Referências e evidências de YouTube |
| /projects | Conversas e contextos salvos |
| /connect | Configuração e estado do modelo |
| /console | Voltar ao terminal |
| /new | Nova conversa, sem apagar anteriores |
| /clear | Limpar apenas a tela; conversa ativa preservada |
| /status | Consultar estado local do servidor |
| Texto livre | Preparar briefing ou enviar ao modelo quando selecionado |

Nenhum dado da barra de endereço, status do celular ou conteúdo externo à interface da imagem foi incorporado ao aplicativo.
