# dSantCreator para Claude

Ler `AGENTS.md` e `.agents/skills/dsant-creator/SKILL.md`. As skills também podem ser instaladas em `~/.claude/skills/` com `python dsant.py install --target claude`.

Claude Code executa scripts somente com as permissões reais da sessão. No Claude web, usar `python dsant.py pack` em um executor e anexar o arquivo exportado; o arquivo oferece contexto, não um terminal remoto nem atualização automática.
