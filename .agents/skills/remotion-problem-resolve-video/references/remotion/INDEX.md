# Remotion — documentação oficial

Consultar documentação primária atual para cada API antes de implementar:
- Visão geral: https://www.remotion.dev/docs/
- 3D: https://www.remotion.dev/docs/three
- Animação: https://www.remotion.dev/docs/animating-properties
- Áudio: https://www.remotion.dev/docs/audio
- Render: https://www.remotion.dev/docs/renderer
- Studio: https://www.remotion.dev/docs/studio

Use ThreeCanvas com width/height. Anime apenas pelo useCurrentFrame; nunca useFrame. Dentro do canvas use Sequence layout=none. Prefira gl=angle; no render por software, swangle. Consulte a referência oficial ao variar versão ou renderer.
