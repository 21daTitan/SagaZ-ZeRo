# Minicurso — Formação NGB / BlackGhost

Fonte: https://www.youtube.com/playlist?list=PLBPobzL8BYoHZPSfnfrPR02eE5Xb4JeLi

15 estudos iniciais por amostragem de legendas automáticas, com tempos, tese, aplicações inferidas, limites e proposta de avaliação. Uma entrada indisponível reportada. Os arquivos foram incorporados do material SagaZ fornecido; não representam análise visual nem revisão integral da playlist.

O núcleo recupera até três estudos de escopo compatível em cada `prepare`. O pacote para chat web inclui uma seleção de estudos conforme o nicho. O manifesto preserva os estados `sampled` e `unavailable`, sem promover coleta parcial a estudo integral.

## Aprofundamento pendente

Para cada aula: coletar mídia/legendas autorizadas; registrar hash; ler toda a transcrição com timestamps e inspecionar mídia quando necessário; produzir síntese própria completa separada do estudo inicial; preservar divergências e registrar a cobertura real. Não promover automaticamente a regra, nem distribuir transcrição integral ou contratar APIs.
